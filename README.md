
# Python Calculator

## Description
A beginner-friendly Python calculator that performs
basic arithmetic operations using user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Invalid number handling
- Menu selection validation

## Technologies Used
- Python 3
- Visual Studio Code

## Concepts Learned
- Variables and user input
- Integers and floats
- Mathematical operators
- Conditional statements (if, elif, else)
- Nested conditionals
- Error handling (try/except)
- ValueError
- F-strings

## How to Run
1. Install Python 3.
2. Download main.py.
3. Open a terminal in the project folder.
4. Run:

   python3 main.py
